# Processed result tables

The following tables are versioned in this repository:

- `results_summary_classification_exploitive.csv`
- `results_summary_classification_explorative.csv`
- `results_summary_regression_exploitive.csv`
- `results_summary_regression_explorative.csv`
- `cv.csv`
- `al_cv_corr.csv`
- `al_se_corr.csv`

The paired trajectory-level tables `al.csv` and `yol.csv` are needed for the
full Figure 1, Figure 3, Figure 4, and supplementary-figure workflows. They
are provided in the companion Zenodo source-data archive and must be placed in
this directory before executing those notebooks.

The Zenodo record will provide a README, a file manifest, checksums, and a
mapping from source tables to manuscript figures and statistics.
